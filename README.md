# KitchDom（キッチダム）

「自分のキッチンの王国を築き、レシピを自在に支配・育成・外食再現・領土開拓まで一括管理する」個人専用レシピプラットフォーム。

ログイン不要・データは端末内（localStorage）のみに保存される個人専用アプリです。

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 実装状況

Phase 1（基盤）を実装済み:

- レシピ一覧・検索（材料からの逆引き含む）・フィルタ
- レシピ追加（すぐ保存 / 詳しく記録、材料ベタ貼り自動分解）
- 家レシピ・外食ログの詳細表示、材料の倍率変更、調理記録、変遷タイムライン
- 外食ログからの再現レシピ化ワークフロー
- レシピ編集
- 今週の献立ピン留め（キッチンタブ）、調理ジャーナル（記録タブ）
- バッジ・称号（ホームの1行サマリー、設定のバッジギャラリー）
- バックアップ（JSON書き出し / 読み込み）

Phase 2以降（キッチンモード本体、買い物リスト合算、PWA対応など）は今後実装予定です。
